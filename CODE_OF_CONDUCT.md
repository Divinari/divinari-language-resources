# Code of Conduct

All contributors uphold the pluralistic Divinari Community Code of Conduct: welcoming native speakers, academics, ministries, NGOs, and heritage communities equally, treating regional/Indigenous languages with full linguistic dignity, and honoring CARE cultural data boundaries.

Report issues privately to **support@divinari.app** (subject: `Code of Conduct Report`).

*Adapted from Contributor Covenant v2.1 (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>).*
